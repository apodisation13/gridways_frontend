# Локальные данные и файлы для Git

Аудит 2026-11-13. `/data` остаётся в `.gitignore`. Git не является резервной копией игнорируемых файлов.

| Исходный файл | Решение | Версионируемая версия |
|---|---|---|
| `data/SEASON_WORKFLOW.md` | Постоянная инструкция перенесена; на старом месте указатель | `docs/seasons/SEASON_WORKFLOW.md` |
| `data/generate_enemies.py` | Код генератора перенесён; старый вызов поддержан маленькой обёрткой | `docs/seasons/generate_enemies.py` |
| `data/levels.tsv` | Рабочий файл оставлен; сохранён исходный снимок 400 уровней сезонов 6–13 | `docs/seasons/reference/levels.tsv` |
| `data/connections.tsv` | Рабочий файл оставлен; сохранён снимок 956 связей | `docs/seasons/reference/connections.tsv` |
| `data/level_enemies.tsv` | Генерируемый результат, оставлен локально (18734 строки при аудите) | Не копируется в Git |
| `data/user_seasons_s1_5.json` | Старый ответ API с пользовательскими ID, прогрессом и статистикой | Оставлен локально; не коммитить как пример |
| `data/.DS_Store` | Служебный файл macOS | Игнорируется |

TSV в `reference/` — исторический снимок, не автоматическая выгрузка актуальной БД и не новая точка записи генератора. В них игровые уровни/связи, без пользовательского прогресса. Они сохраняют авторскую работу, которую нельзя восстановить одним генератором врагов. Для новых сезонов актуальность ID и пулов врагов нужно проверить отдельно.

После свежего клонирования при необходимости подготовить рабочие данные:

```sh
mkdir -p data
cp docs/seasons/reference/levels.tsv data/levels.tsv
cp docs/seasons/reference/connections.tsv data/connections.tsv
python3 docs/seasons/generate_enemies.py --data-dir data
```

Не копировать reference поверх своей более свежей работы. Генератор перезаписывает `levels.tsv` и `level_enemies.tsv`, использует seed 42 и правила сезонов 6–13. Для экспериментов копировать входные данные в временную папку и использовать `--data-dir`. Для сезонов вне правил назначения врагов не сохраняются в новом `level_enemies.tsv`; проверить алгоритм перед расширением на другие сезоны.

Две папки для материалов проекта: `data/` — локальная и игнорируемая; `docs/` — документация, примеры и скрипты для Git. Скрипты лежат рядом со своей тематической документацией. `AGENTS.md` и скрытая `.agents/skills/` — служебные точки входа агента, они тоже коммитятся. Коммит не создан автоматически. `.env.docker` уже был локальным untracked-файлом; его не меняли и не включали в документацию.
